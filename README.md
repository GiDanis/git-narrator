## ⚡ The 2026 Problem: "Review Burnout"

AI coding assistants (Claude Code, Cursor, Windsurf, Copilot, Cline) generate 500 lines of refactored code in seconds. The new bottleneck in software engineering is no longer *writing code* — it is **understanding, verifying, and reviewing opaque diffs**.

Standard `git diff` leaves you drowning in walls of red and green lines with zero context. Existing AI commit generators merely regurgitate shallow syntax summaries, crash when large lockfiles are staged, and take 15–30 seconds to run.

**`git-narrator` fixes this.** It acts as an elite Principal Architect and Security Auditor inside your terminal, transforming complex diffs into structured executive stories, negative-space risk radars, and visual system flows in milliseconds.

## ✨ Key Capabilities

### 1. 🧠 The Executive Story (Before vs After)
Does not just list files. It identifies the architectural intent, explains the mental model shift, categorizes component mutations, and explicitly calls out newly incurred technical debt.

### 2. 🛡️ Negative-Space Risk Radar
Analyzes what is **missing or broken** rather than just what is written:
- **`CONTRACT_BREAK`**: Altered public signatures, breaking DB schema changes, modified API response shapes.
- **`TEST_GAP`**: New conditional branches, error handlers, or business logic added without test coverage.
- **`SECURITY_LEAK`**: SQL injection, SSRF, permissive CORS, unsanitized inputs, unhandled auth errors.
- **`HALLUCINATED_DEPENDENCY`**: Catches phantom packages generated by AI code assistants (*slopsquatting*).

### 3. 🗺️ Visual Architecture Flows
Automatically synthesizes system mutation flows in clean **ASCII** for instant terminal reading, alongside copy-ready **Mermaid diagrams** (`flowchart` / `sequenceDiagram`) for PR descriptions and documentation.

### 4. ⚡ Lockfile Delta Compactor & Knapsack Token Optimizer
A 10,000-line diff is usually 90% lockfile noise. `git-narrator` parses `package-lock.json`, `pnpm-lock.yaml`, `yarn.lock`, `Cargo.lock`, `poetry.lock`, and `uv.lock`, stripping thousands of lines of hashes while preserving high-signal security metadata (e.g. `[UPGRADE] axios 1.2.0 -> 1.7.9`).

### 5. 🔒 100% Local-First & Zero Vendor Lock-in
- **Local Ollama** (Default): Auto-detected at `localhost:11434`. Zero cost, runs completely offline, code never leaves your workstation.
- **Google Gemini**: Sub-second execution using free tier with huge context windows.
- **OpenAI / Groq / DeepSeek / Claude**: Fully supported via native REST streaming.

### 6. 🚀 Sub-35ms Cold Start & Zero SDK Bloat
No heavyweight official vendor SDKs that bloat your disk by 150MB. Built on raw asynchronous `httpx` with tiered lazy imports.

### Run with `uvx` (Recommended — Zero Installation)

```bash
# Via uv:
uv tool install git-narrator

# Via pip:
pip install git-narrator
```

Because Git looks for executables starting with `git-` in your `$PATH`, you can run it natively as:
```bash

```

## ⌨️ Common Workflows & Commands

### 1. Auto-Detect Mode (Zero Arguments)
```bash
git narrator
```
Intelligently inspects:
1. Staged changes (`git diff --staged`) if present.
2. Unstaged modifications (`git diff`) if no files are staged.
3. Recent commit (`HEAD`) if working directory is clean.

### 2. Instant Commit Generation
```bash
# Generate Conventional Commit and apply immediately:
git narrator commit

# Or non-interactive for scripts:
git narrator commit -y
```

### 3. Pull Request Markdown Generator
```bash
# Generate rich PR markdown and copy to clipboard via OSC 52:
git narrator pr
```

### 4. Specific Commits or Branch Ranges
```bash
# Explain the last 3 commits:
git narrator diff HEAD~3..HEAD

# Inspect a feature branch compared to main:
git narrator diff main..feature

# Code archaeology on a historical commit:
git narrator diff a1b2c3d
```

### 5. Force Local Mode (Offline & Private)
```bash
git narrator --local
```

### 6. Check Active Provider Configuration
```bash
git narrator config
```

## 🛡️ CI/CD Quality Gate (GitHub Actions)

Use `git-narrator` as an automated architectural risk gate in your pull request pipelines:

```yaml
name: "Architecture & Risk Audit"
on: [pull_request]

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Run git-narrator Security Gate
        env:
          GEMINI_API_KEY: ${{ secrets.GEMINI_API_KEY }}
        run: |
          pip install git-narrator
          # Fails pipeline with exit code 1 if CRITICAL or HIGH risk is found:
          git-narrator diff origin/main...HEAD --fail-on-risk HIGH
```

## ⚙️ Configuration

`git-narrator` works out-of-the-box with zero configuration. If you wish to customize defaults, create `~/.config/git-narrator/config.json`:

```json
{
  "provider": "ollama",
  "model": "qwen2.5-coder:7b",
  "ollama_base_url": "http://localhost:11434"
}
```

Or set standard environment variables:
- `GEMINI_API_KEY` (Google Gemini)
- `OPENAI_API_KEY` (OpenAI / Groq / DeepSeek)
- `ANTHROPIC_API_KEY` (Claude)
